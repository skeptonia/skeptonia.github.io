MAIN MACHINE
NISSAN 400Z
YSM 400Z — первый в России профессиональный гоночный автомобиль для дрифта на базе Nissan Z (RZ34). Двигатель 2JZ-GTE Billet Block с турбиной Precision 6870. Блок управления двигателем MoTeC M1. Мощность 970 л.с. В качестве топлива используется специализированное BRFuel E85+. 4-ступенчатая секвентальная коробка передач Gearset. Сцепление OS Giken. Кардан и привода Driveshaft. Спортивный редуктор Winters. Развесовка: передняя ось 55% задняя ось 45%.
